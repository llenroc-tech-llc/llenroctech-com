# Portfolio image guidelines

Use approved project screenshots or existing licensed repository assets. Prefer WebP, a consistent 16:10 crop, explicit dimensions, descriptive alt text, and lazy loading below the fold. Do not include browser chrome, private data, unrelated stock images, or fabricated product screens. When a verified screenshot is unavailable, the card uses the branded text panel; replace it by adding `image` and `imageAlt` to the data object.
