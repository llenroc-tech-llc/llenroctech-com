# LlenrocTech.com

Repository layout:

- `frontend/llenroctech-web` - Angular website.
- `backend/llenroctech-api` - Java API skeleton for the future backend.
- `netlify/functions` - temporary legacy Netlify Functions backend.
- `infrastructure/azure` - Azure Function deployment source.
- `infrastructure/docker` - Docker-related infrastructure files.
- `infrastructure/netlify` - Netlify support files.
- `docs` - architecture, API, deployment, and screenshot documentation.

Common commands:

```bash
npm run build --prefix frontend/llenroctech-web
npm run start:netlify --prefix frontend/llenroctech-web
```
